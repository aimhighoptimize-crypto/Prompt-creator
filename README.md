# Prompt Architect

An AI-powered tool that turns a messy description of what you want an AI to do into a
sophisticated, model-specific prompt — with clarifying questions, quality scoring, and a
plain-English explanation of what the generated prompt actually asks for.

**Status: Phase 1 — research and architecture only. No application code yet.**

See [`docs/BLUEPRINT.md`](docs/BLUEPRINT.md) for the full product blueprint: competitive
analysis, prompt-quality framework, model-specific strategy (Claude / ChatGPT / Gemini /
Perplexity / Grok), technical architecture, V1 scope, and the Phase 2 build specification.
